# Configuration files

- `model_configuration.json`: architecture, targets, losses, training,
  evaluation and formal map settings.
- `facies_configuration.json`: exact two-stage facies clustering parameters,
  including imputation, scaling and cluster centres.
- `environment_features.json`: ordered environmental feature list, the added
  age-proxy channel and land-mask exclusion.

All paths in the executable commands are supplied explicitly. These
configuration files therefore contain scientific settings rather than local
computer paths.

The sample inventory and geochemical source references are given in the
accompanying manuscript's `Supplementary_Data_1_Geochemistry_and_Inputs.xlsx`.

# Data and model reuse

The MIT license covers the authors' Python source code and software documentation.
Compiled measurements, external grids, plate-boundary data and their derivatives
retain the terms of the original providers listed in data/SOURCES.md. Attribution
to those sources is required. A source-code license does not relicense third-party
data. Check the linked provider terms for the intended redistribution or reuse.

The authors make their trained model checkpoints and original prediction products
available under Creative Commons Attribution 4.0 International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/ . Cite this software release and the
accompanying article. Provider rights in input material remain applicable.
